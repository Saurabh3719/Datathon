How to use this dashboard for the best information gain

Five habits that get you from "looking at charts" to "finding the finding."

  1. Start on Overview for the headline numbers -- transaction volume, value, success rate, chargeback count -- before drilling into any one page.
  2. Use the left-rail slicers to narrow by date, category, or status; every KPI and chart on that page updates together, so comparisons stay apples-to-apples.
  3. Don't just read a number -- ask the chatbot the same question in plain English to see the exact SQL and joined tables behind it.
  4. Check the Workflow page once to understand how raw files became this data model -- it makes every KPI's caveats obvious (e.g. why "no matching merchant" is its own category).
  5. Finish on Fraud-Ring Spotlight -- it's built specifically to surface the merchants and users an averages-only view would hide.

FAQ

Is any of this real customer data?
No -- it's a deliberately messy synthetic dataset built for the datathon. PAN and Aadhaar-shaped fields are masked regardless.
How does the chatbot avoid making numbers up?
Every answer runs a real, read-only SQL query first (checked by is_read_only()), then a second call turns the actual returned rows into a sentence -- it never answers from "memory."
What's the difference between a "local template" and "OpenRouter" answer?
21 common questions are answered by fixed, hand-checked SQL templates -- free, instant, zero network calls. Anything else falls back to an LLM call via OpenRouter, which plans its own SQL but must still pass the same safety check.
Why do some charts show a "No Matching Merchant/Customer" category?
Only ~48% of transactions match a real merchant record and ~32% match a real customer record -- that's an intentional feature of this dataset, not a bug. Rather than hide it, every join gap is its own labelled category.
Can I trust the Power BI numbers to match the chatbot's numbers?
Yes -- both read the exact same four cleaned CSVs (data/cleaned/). There's only one source of truth in this project.
How do I re-run the whole pipeline myself?
See the root README.md -- in short: python3 scripts/clean_pipeline.py then compute_metrics.py, build_dashboard.py, build_powerbi_project.py, and agent/build_db.py.
