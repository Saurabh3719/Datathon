1

Data Cleaning -- Raw Files to Star Schema

Four deliberately messy source files (inconsistent IDs, currency formats, timestamp formats, PAN/Aadhaar formats) are run through clean_pipeline.py, which standardizes every field and writes an analytics-ready star schema. Nothing is silently dropped -- unrecoverable values are flagged with explicit boolean columns instead.

KPI Integration -- Star Schema to Metrics

The same four tables feed two parallel metrics engines: scripts/compute_metrics.py (Python, powers the HTML dashboard + business report) and 30+ DAX measures (powers Power BI). Both read identical source tables, so every number matches across surfaces.

End-to-End Project Architecture

One cleaning pipeline, three independent consumers -- the offline HTML dashboard, the native Power BI report, and the text-to-SQL chatbot -- all reading the exact same cleaned CSVs, so there is only ever one source of truth.

How the Chatbot Reads the Data

Every answer is grounded in a real, read-only SQL query against the same star schema -- never a hallucinated number. 21 vetted local templates cover the common questions for free; anything else falls back to an OpenRouter LLM call that must still pass the same safety check before it can run.
